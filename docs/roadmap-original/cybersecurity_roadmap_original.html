▾

🎯 Objetivos
  • Dominar el modelo OSI/TCP-IP a nivel profundo
  • Administrar Linux con fluidez desde terminal
  • Entender cómo funciona el tráfico de red
  • Configurar y usar Wireshark para análisis
  • Virtualización con VirtualBox/VMware
📚 Temas Clave
Modelo OSI / TCP-IPSubnetting / CIDR DNS, DHCP, HTTP/SBash scripting Permisos LinuxVirtualización Wireshark basicsSSH, FTP, SMB Routing & SwitchingFirewall básico
📖 Recursos Principales

  • TryHackMe: Pre-Security Path (gratis)
  • Libro: Computer Networking – Tanenbaum
  • YouTube: NetworkChuck, David Bombal
  • Linux: OverTheWire: Bandit (wargame)
🧪 Proyectos Prácticos
  • Capturar y analizar tráfico HTTP/DNS con Wireshark
  • Montar red virtual (3 VMs) con VirtualBox
  • Script Bash para inventario de red automático
  • Completar OverTheWire Bandit (25 niveles)
✅ Criterios para Avanzar

  • Identificar tipos de tráfico en capturas de Wireshark
  • Escribir scripts Bash funcionales de 50+ líneas

🔬 Laboratorio Personal de Ciberseguridad

Guía paso a paso para construir tu home lab desde cero

💻Hardware recomendado mínimo: PC/laptop con 16 GB RAM (32 GB ideal), 500 GB SSD. Puedes empezar con 8 GB pero tendrás limitaciones. En tu contexto en Huacho, busca equipos usados con estas specs.

📋 Construcción del Lab por Fases

1

Hypervisor Base (Mes 1–2)

Instala VirtualBox (gratis) o VMware Workstation Player (gratis). Luego VMware Pro o Proxmox cuando necesites más control. En una sola máquina física puedes correr 3-4 VMs simultáneas con 16 GB RAM.

2

VMs Esenciales – Fase 1

Kali Linux 2024: tu estación de ataque principal. Ubuntu Server 22.04: objetivo y servidor de servicios. Windows 10: cliente víctima. Metasploitable 3: objetivo vulnerable intencional. Todas en red NAT aislada.

3

Red de Active Directory (Mes 5–8)

Agrega Windows Server 2022 (trial gratuito 180 días) como Domain Controller. 1-2 Windows 10 clients unidos al dominio. Esta arquitectura simula entornos corporativos reales donde ocurre el 80% de los ataques.

4

Stack de Defensa – SIEM (Mes 9–14)

Wazuh (gratis, recomendado): instalar como manager en Ubuntu Server. Conectar todos los agentes de las VMs. Alternativamente Elastic Stack (ELK) con Logstash. Para Splunk, usa la versión gratuita (500 MB/día de ingesta).

5

Laboratorio de Malware (Mes 31+)

VM Windows completamente aislada (sin acceso a internet real), con REMnux y FlareVM. Snapshots antes de cada análisis. Usa FakeNet-NG para simular conectividad. NUNCA ejecutes malware en tu máquina principal.

6

Cloud Lab Gratuito (Mes 23+)

AWS Free Tier (12 meses gratis): EC2, S3, IAM. Azure for Students (con correo universitario): $100 de crédito. Google Cloud: $300 de crédito inicial. Usa CloudGoat (Rhino Security Labs) para escenarios vulnerables en AWS.

🐧 Distribuciones Linux a Dominar

  • Kali Linux – estación de ataque principal (obligatorio)
  • Parrot OS Security – alternativa a Kali, más ligero
  • BlackArch – para herramientas avanzadas adicionales
🔵 Defensa / Análisis
  • Ubuntu Server LTS – administración de servicios

🎯 Recomendación para tu Perfil Específico

Con tu base en Ingeniería de Sistemas, conocimiento de programación y redes, y disposición a invertir 4 años, la trayectoria más estratégica es:

SOC Analyst L1 (primer empleo, meses 14–18) → Pentester Junior (año 2–3) → Cloud Security / Red Team Senior (año 4+).

Alternativamente, si disfrutas más el código: DevSecOps aprovecha directamente tus habilidades de programación PHP/Python y tiene de las perspectivas salariales más altas en remoto. Plataformas como Toptal, Deel o LinkedIn Jobs te permiten trabajar para empresas USA/Europa desde Huacho.

Proyectos concretos que demuestran competencia a empleadores
